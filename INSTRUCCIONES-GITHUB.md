# Publicar el regalo para Ali

El proyecto ya está preparado para un repositorio llamado `Cumple`.

1. Descomprime el ZIP.
2. Sube **el contenido completo** de la carpeta al repositorio `Cumple`. Debe incluir la carpeta `.github`.
3. En el repositorio abre `Settings` → `Pages`.
4. En `Build and deployment` → `Source`, elige `GitHub Actions`.
5. Abre `Actions` y espera a que `Publicar Cumple en GitHub Pages` termine en color verde.

La página quedará en:

`https://TU-USUARIO.github.io/Cumple/`

No selecciones `Deploy from a branch`. Cada cambio que subas a `main` volverá a publicar la página automáticamente.
